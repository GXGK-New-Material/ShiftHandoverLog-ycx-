# 🏭 交接班记录管理系统

一个轻量级的交接班记录录入与查看工具，纯前端实现，无需后端服务器。

## ✨ 功能特性

- **📝 数据录入**：按交班模板结构化填表，自动生成作业情况文本
- **👁️ 实时预览**：填写时自动生成符合模板格式的文本摘要
- **📋 记录查看**：按炉号、日期、班次筛选，支持关键词搜索
- **✏️ 编辑管理**：支持编辑、删除、复制单条记录
- **📤 导出 Excel**：导出格式与交班日志模板一致，支持4个炉号独立sheet
- **📥 导入数据**：支持导入 Excel 交班日志或 JSON 备份文件
- **💾 本地存储**：数据保存在浏览器 localStorage，无需服务器
- **📱 响应式设计**：适配电脑、平板和手机

## 🏗️ 支持的炉号

- 101炉
- 102炉
- 201炉
- 202炉

## 🚀 使用方式

直接用浏览器打开 `index.html` 即可使用，无需安装任何依赖。

```bash
# 或者部署到任意静态服务器
npx serve .
```

## 📋 交班模板字段

录入表单覆盖以下关键字段：

| 分类 | 字段 |
|------|------|
| 出铁信息 | 出铁炉数、南北炉数、铁口操作、铁口深度 |
| 南/北面情况 | 炉温（流动性）、流量、卡堵、通拉、吹氧、排碳、渣量 |
| 炉况电流 | 炉况、电流、炉压、冲火、塌料 |
| 电极系统 | 三相电极压放量、电极位置 |
| 系统状态 | 炉内温度、电极压放、液压系统、水冷系统、机电设备 |
| 其他 | 变料情况、异常交班、补充说明 |

## 🔧 技术栈

- 纯 HTML + CSS + JavaScript（零依赖框架）
- [SheetJS](https://sheetjs.com/) (xlsx) - Excel 导入导出
- localStorage - 本地数据持久化
